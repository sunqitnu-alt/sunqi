## 项目经历

### 智能旅行规划 Agent 系统

- 项目定位：AI 旅行规划产品 / 多轮对话 Agent / 可落地 Demo
- 技术栈：Python、LangChain、LangGraph、FastAPI、Vue3、MongoDB、Redis

项目面向自然语言旅行规划场景，设计一个可多轮对话、可打断、可微调、可重写行程的 AI 旅行助手。用户可以输入目的地、预算、天数、偏好等需求，系统根据真实 POI、天气和交通路线生成旅行计划，并支持用户持续修改。

**产品与设计工作：**

- 梳理用户从“提出需求 → 补充偏好 → 生成行程 → 修改方案 → 查看详情”的核心路径，明确 Agent 在不同阶段需要收集的信息和反馈方式。
- 设计多轮对话下的状态流转逻辑，支持用户随时通过自然语言打断、补充约束或重写计划，提升交互自由度。
- 将高德地图 POI 搜索、天气查询、多交通路线规划等真实服务封装为工具调用，降低大模型幻觉，让生成结果更接近真实可执行方案。
- 参与 FastAPI 接口、Vue3 页面、会话状态和行程快照设计，完成从 Agent 推理到前端展示的完整体验闭环。

**可体现能力：**AI 产品流程设计、Agent 交互设计、工具调用方案设计、Demo 落地、技术与产品协同。

### OCT 影像智能分析平台

- 项目定位：医学影像 AI 平台 / 多模型能力整合 / 智能工作流
- 技术栈：LangChain、LangGraph、RAG、MCP、Faiss、BM25、Function Call、Electron

项目面向 OCT 影像分析场景，整合课题组多个成熟深度学习模型，将支架检测与三维重建、关键帧提取与渲染、斑块分割、病例检索、血栓识别、坐标转换等功能接入统一平台。

**产品与设计工作：**

- 梳理复杂医学影像分析流程，将多个分散模型能力拆解为可被智能体调用的功能模块，降低用户操作成本。
- 基于 LangGraph 构建 ReAct 智能体，使系统能根据分析目标自主规划任务步骤，减少用户在多个工具之间手动切换。
- 使用 Faiss + BM25 构建病例检索方案，帮助用户在分析过程中快速获取相似病例和相关信息。
- 通过 Function Call / MCP 接入深度学习模型，推动平台从“模型集合”转向“统一智能分析工作台”。

**可体现能力：**复杂场景抽象、AI 工作流设计、多模型平台化、医学 AI 产品理解、检索体验优化。
