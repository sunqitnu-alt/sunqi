## 4. 项目经历

### 项目一：基于 LangChain 的智能旅行规划 Agent 系统

- 技术栈：Python、LangChain、LangGraph、FastAPI、Vue3、MongoDB、Redis
- 项目简介：面向自然语言旅行规划场景，构建一个可多轮对话、可修改、可重写行程的智能旅行规划 Agent 系统。
- 主要工作：
  - 使用 LangChain 构建底层智能体逻辑，引入 LangGraph 管理多轮对话中的复杂状态流转。
  - 实现上下文记忆提取、意图路由、节点流转，支持用户随时通过自然语言中断、微调或重写当前旅行计划。
  - 将高德地图 API 中的 POI 搜索、天气查询、多交通路线规划封装为 LangChain 自定义工具链。
  - 采用 ReAct 范式驱动 Agent 按需调用外部服务，减少大模型幻觉，提升行程方案真实落地性。
  - 使用 FastAPI 搭建接口层，基于 Redis 和 MongoDB 实现会话状态和行程快照持久化。
  - 前端采用 Vue3 + TypeScript 构建交互界面，并编写 Docker 脚本完成全栈容器化部署。
- 可强调能力：Agent 架构设计、工具调用、状态管理、全栈联调、AI 应用落地。

### 项目二：基于 SegFormer 的道路裂缝图像语义分割系统

- 技术栈：Python、PyTorch、SegFormer、Mix Transformer、计算机视觉
- 项目简介：围绕道路裂缝像素级识别任务，完成图像数据清洗、模型训练、指标评估和结果分析。
- 主要工作：
  - 引入轻量级 SegFormer 架构，解决传统 CNN 感受野受限问题。
  - 使用 Mix Transformer 替代卷积骨干网络，通过 Overlapping Patch 机制提取多尺度特征。
  - 采用纯 MLP 解码器融合多尺度特征，降低计算复杂度。
  - 针对裂缝与背景像素极度不均衡问题，采用 Dice Loss 与交叉熵损失联合优化模型参数。
  - 独立完成近 4000 张图像的数据清洗与端到端训练闭环。
  - 模型迭代约 16 万步后稳定收敛，测试集平均交并比 mIoU 达 80%，准确率接近 100%。
- 可强调能力：深度学习训练、图像分割、数据处理、模型评估、科研实践。

  - 基于 LangGraph 构建 ReAct 核心智能体，实现影像分析任务的自主规划与执行。
  - 使用 Faiss + BM25 构建病例检索引擎。
  - 通过 Function Call / MCP 集成深度学习模型，支持分布式模型调用。
