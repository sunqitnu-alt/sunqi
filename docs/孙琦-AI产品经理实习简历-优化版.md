- 项目定位：AI 旅行规划产品 / 多轮对话 Agent / 可落地 Demo

- **需求拆解与核心路径设计：**围绕用户“想快速得到可执行旅行方案”的目标，拆解“提出需求 → 补充偏好 → 生成行程 → 修改方案 → 查看详情”的主流程，明确 Agent 在不同阶段需要收集的信息、反馈方式和异常处理。

### OCT 影像智能分析平台

- 项目定位：医学影像 AI 平台 / 多模型能力整合 / 智能工作流
- 技术栈：LangChain、LangGraph、RAG、MCP、Faiss、BM25、Function Call、Electron

面向 OCT 影像分析场景，整合课题组多个成熟深度学习模型，将支架检测与三维重建、关键帧提取与渲染、斑块分割、病例检索、血栓识别、坐标转换等能力接入统一平台。

- **复杂场景抽象：**梳理医学影像分析流程，将多个分散模型能力拆解为可被智能体调用的功能模块，降低用户在多个工具间切换的操作成本。
- **智能工作流设计：**基于 LangGraph 构建 ReAct 智能体，使系统能根据用户分析目标自主规划任务步骤，推动平台从“模型集合”转向“统一智能分析工作台”。
- **检索体验优化：**使用 Faiss + BM25 构建病例检索方案，帮助用户在分析过程中快速获取相似病例和相关信息，为 RAG 问答与辅助分析提供基础。
- **模型能力产品化：**通过 Function Call / MCP 接入深度学习模型，设计统一调用入口和交互方式，使底层模型能力能够以平台功能形式被使用。
