Projects

代表项目

智能旅行规划 Agent 系统

Python · LangChain · FastAPI · Vue3

面向自然语言出行需求，构建可多轮交互的旅行规划 Agent，支持用户围绕预算、天数、偏好和临时修改进行持续对话。

  • 使用 LangGraph 组织状态流转、意图路由、计划生成与用户打断。
  • 封装高德地图 POI、天气、交通路线等工具调用，提升规划结果可落地性。
  • 完成 FastAPI 接口、Vue3 页面与会话数据持久化，打通完整 Demo 链路。

道路裂缝语义分割系统

Python · PyTorch · SegFormer

围绕道路裂缝像素级识别任务，完成数据清洗、模型训练、指标评估与可视化，重点处理小目标和类别不均衡问题。

  • 采用 SegFormer + Mix Transformer 建模多尺度特征和长程依赖。
  • 结合 Dice Loss 与 CE Loss 优化裂缝细粒度边界识别效果。
  • 处理近 4000 张图像，测试集 mIoU 达 80%，准确率接近 100%。

OCT 影像智能分析平台

Python · RAG · LangGraph · MCP

整合课题组多个成熟深度学习模型，搭建统一的 OCT 影像分析平台，将支架检测与三维重建、关键帧渲染、斑块分割、病例检索、血栓识别等功能接入同一工作流。

  • 基于 LangGraph 构建 ReAct 智能体，根据分析目标自动规划任务步骤。
  • 通过 Function Call / MCP 接入不同深度学习模型，降低多模型系统耦合度。
  • 使用 Faiss + BM25 进行病例检索，提高影像分析过程中的信息获取效率。
